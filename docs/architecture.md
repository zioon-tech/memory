# Product boundaries

Memory 拥有服务、存储、账户到 drive 的映射、官网、文档、SDK 和 Agent Skill。Zioon 拥有账户身份服务、Runtime 的授权与执行，以及工作台的 Memory Provider 接入。

Memory 通过身份验证接口检查当前账户和权限；不会自行复制 Zioon 的账户数据库。跨产品请求使用限定路径与操作的短期委托；写入超时应视为结果未知，读取并核对之后再决定是否重试。

文件操作在同一账户内串行，以保持字节内容、版本和 JSONL 去重一致。服务目前为单实例；启用多副本前需要共享事务调度机制及适合多副本的元数据存储。

官网和文档的独立发布制品由 `build:site` 生成。控制台与登录流程依赖服务端账户交接，不能作为静态页面替换它们。生产 Caddy 仅为公开官网、文档及其静态资源配置独立发布目录。
